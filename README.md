# DIA Launcher updates

The newest version of DIA Launcher, as the installed program fetches it: `latest.json` and the installer in pieces.
Currently 0.27.66.

To put the installer together by hand (Windows, in this folder):

    copy /b DIA-Launcher-Setup-0.27.66-x64.exe.001 + DIA-Launcher-Setup-0.27.66-x64.exe.002 DIA-Launcher-Setup-0.27.66-x64.exe
